EMBERLINE — a round-based 5v5 tactical FPS that runs entirely in the browser. Counter-Strike-style bomb plant/defuse rounds against AI bots on an original three-lane map (Meridian Depot): a buy economy between rounds, five distinct weapons, frag/smoke/flash grenades, armor, headshots, recoil and spread, bot squads that follow routes, hold angles, react to sight and sound, and play the objective. First to 5 rounds takes the match, with a half-time side swap. Static files, no build step, fully offline — three.js 0.187.0 is vendored and every texture and sound is generated procedurally at runtime.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
